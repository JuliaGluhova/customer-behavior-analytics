# Customer Behavior Analytics

## О проекте

**Customer Behavior Analytics** — веб-приложение для анализа поведения потребителей в электронной коммерции и прогнозирования вероятности совершения покупок с использованием методов машинного обучения.

Проект разработан в рамках научно-исследовательской работы и направлен на выявление закономерностей потребительского поведения на основе данных о посещениях интернет-магазина.

## Основные возможности

Приложение включает следующие функциональные разделы:

- **Главная** — описание проекта и его основных возможностей.
- **Загрузка и анализ данных** — изучение структуры исходного набора данных, характеристик и распределения признаков.
- **Сегментация потребителей** — разделение пользователей на группы с использованием алгоритмов кластеризации.
- **Прогнозирование покупок** — определение вероятности совершения покупки с помощью моделей машинного обучения.
- **Сценарный анализ поведения потребителей** — исследование прогнозов моделей для различных групп пользователей.
- **Итоговые результаты** — представление результатов вычислительных экспериментов и сравнение моделей.

## Используемые алгоритмы

В проекте реализованы следующие методы машинного обучения:

- **K-Means** — сегментация потребителей по характеристикам пользовательских сессий.
- **Logistic Regression** — прогнозирование вероятности совершения покупки.
- **Random Forest** — классификация пользовательских сессий и прогнозирование покупательской активности.

## Исходные данные

Для исследования используется набор данных **Online Shoppers Purchasing Intention Dataset**, размещённый в UCI Machine Learning Repository.

Набор содержит 12 330 пользовательских сессий и 18 признаков, характеризующих поведение посетителей интернет-магазина. Целевая переменная Revenue показывает, завершилось ли посещение совершением покупки.

Источник: https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention

## Установка и запуск

**1. Клонирование репозитория**

```bash
git clone https://github.com/USERNAME/customer-behavior-analytics.git
```

**2. Переход в папку проекта**

```bash
cd customer-behavior-analytics
```

**3. Создание виртуального окружения**

```bash
python -m venv .venv
```

**4. Активация виртуального окружения**

```bash
.venv\Scripts\activate
```

**5. Установка зависимостей**

```bash
python -m pip install -r requirements.txt
```

**6. Запуск приложения**

```bash
streamlit run app.py
```

После запуска приложение открывается в браузере по локальному адресу, указанному в терминале.
